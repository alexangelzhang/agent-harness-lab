# Agent Memory：从聊天记录到可检验的长期记忆

## 出处

- 知乎文章一：https://zhuanlan.zhihu.com/p/2102790787461280339
- 知乎文章二：https://zhuanlan.zhihu.com/p/2102459954288448107

本文是浓缩与落地记录，不是逐字翻译。下文把文章转述的框架、作者强调的工程判断和本仓库的实现分开写，避免把外部实验结果当成本项目收益。

## 一、文章转述的框架：记忆有四层

1. **Transcripts（原始记录）**：完整交互证据，负责回答“当时到底发生了什么”。
2. **Memory Notes（记忆笔记）**：从经历中挑出的可复用事实、偏好和教训。
3. **Representations（表示）**：Wiki、摘要、层级索引等导航结构，帮助后续查找。
4. **Injected Context（注入上下文）**：本轮真正交给模型的内容，受注意力和 token 预算约束。

四层不能互相顶替。Wiki 丢掉的细节仍应能回到原始记录检索；注入了索引也不等于模型一定会遵循，更不意味着正文已经加载。

## 二、作者强调的工程判断

### 1. 写入是在预测未来需求

不是所有对话都值得留。长期记忆的核心是残差：删掉之后无法从环境重新观测的信息。当前余额、开关状态、页面内容等可以重新读取，驻留反而制造旧值。知识半衰期短于维护周期的候选，也不值得长期维护。

### 2. Dreaming 是整理，不是凭空生成真理

离线整理包括创建笔记、纠错、构建表示、上提高价值内容、聚焦后续入口和修复断链。纠错需要原始记录中的反证；低置信内容转正也需要确认证据。模型自己的第二次猜测不能充当证据。

观察、推断、已验证和失效知识应分开标记。生命周期里的 ACTIVE 只表示当前可用，不能代替知识来源和验证状态。

### 3. 表示层必须有压缩边界和回程

Wiki 页面应保留来源，体积需要预算，断链需要审计和修复。修复不能把读者导向另一张不存在的页面。关键条款应保留原文，不能为了缩短摘要改掉约束含义。

### 4. 顶层上下文优先放索引

顶层入口适合放少量高可信指针，例如记忆标识、标签、来源、知识状态和版本。正文按需检索。预算要同时限制行数和实际 UTF-8 字节；仅限制条数，仍可能被长文本打爆。

### 5. 共享写必须防旧版本覆盖

两个整理者可能同时读到同一版本。先完成写入的人推进版本后，后写者若仍拿旧版本，就必须失败，不能静默覆盖。证据检查和版本检查都要通过。

### 6. 效果要看后续需要与使用

文件更多、摘要更长都不等于记忆更好。precision 看写入项后来有多少真的被使用，recall 看后续需要项当时有多少已经写下。需要集合应来自任务或评测标注，不由模型自报。

## 三、证据边界

文章中的跨模型比较受题量、任务构成、调用成本和沙箱条件影响；这些条件没有完全归一，不能据此推出本仓库的准确率、成本下降或任务收益。离线落地验证的是确定性机制：该拒绝的写入会被拒绝、旧版本不能覆盖、索引不超预算、指标按约定口径计算。后文的真实对照只报告当前配置模型在同一批虚构任务上的小样本表现，不证明模型普遍会更会判断什么值得记。

## 四、本仓库落地

| 文章机制 | 代码入口 | 落地行为 |
|---|---|---|
| 知识状态与版本 | `Memory`、`MemoryStore` | 增加 `OBSERVED / INFERRED / VERIFIED / STALE` 与 `revision`；保留旧构造，所有实际变更递增版本 |
| 残差写入 | `ResidualMemoryGate` | 拒绝可重观测状态和半衰期低于维护周期的候选，并给出可读原因 |
| 原始证据 | `MemoryTranscript` | 只接受真实出现在原始记录中的非空证据 |
| 离线整理 | `MemoryDreamer` | 组合笔记创建、纠错、上提、表示构建和断链修复；失败路径不改原文 |
| Wiki 表示 | `MemoryWiki` | 强制来源存在，限制正文总字节，审计断链，只向已有页面重定向 |
| 聚焦注入 | `MemoryContextBudget`、`RecallPipeline` | 显式启用后只渲染长期记忆索引，同时限行数与 UTF-8 字节；默认全文行为不变 |
| 预测评价 | `MemoryPredictionBench` | 聚合写入、后续需要和实际使用集合；空分母返回 `NaN`，非法使用集合直接报错 |
| 真实答案判分 | `MemoryAnswerBench` | 禁用值优先判为污染，再按完整期望标识和拒答标记分为答对、拒答、其他错误 |

没有引入向量数据库、外部 Wiki 服务、新依赖或环境变量，也没有实现通用自然语言矛盾识别。结构化证据由调用方提供，代码负责核验它确实存在。

### 动态工作流补充（2026-11-09）

Anthropic Managed Agents Cookbook 的多 transcript 动态整理已补到同一记忆层：`MemoryDreamingWorkflow` 做分批独立分析、失败台账和一次集中整理；`MemoryStore.merge` 新增版本化重载；`MemoryInputSanitizer` 同时净化分析输入和候选输出；`MemoryOrganizer` 提供去重、完整索引、移动存根和冲突并列；`MemoryNightlyWindow` 只在完整成功时推进游标，运行中输入不自动补抓。消费侧复用 `ToolPolicy.readOnlyAllowlist()`，上一轮五幕和旧公共入口保持可用。

完整原文浓缩、托管服务边界和本轮 6 个真实样本见 `docs/anthropic_cma_dynamic_dreaming.md`。本轮没有接 Managed Agents API、30 天版本服务或 cron，也没有把原文成本数字写成本地收益。

## 五、真实模型同题 A/B（2026-11-09）

运行模型为 `kimi-k2-0905-preview`，每臂 3 遍，共 8 臂、24 个实验样本。三片各先用一次 `ProtocolProbe` 预检；所有样本均在最多 4 轮内以合法 `Finish` 收口。下表不含探针调用。

判分口径是 `CORRECT / CONTAMINATED / ABSTAINED / WRONG`：只要出现禁用值就判污染，即使同时出现新值；只有命中完整期望标识且不含禁用值才判答对；“不知道”和“无法确定”单列拒答，不记答对。行为分类不设退出门槛。

| 实验 | 对照臂 | 答对 | 污染 | 拒答 | 其他错误 | LLM / read_memory 总次数 | 初始记忆总量 / 均值（字节） | 累计请求总量 / 均值（字节） |
|---|---|---:|---:|---:|---:|---:|---:|---:|
| 纠错 | 无记忆 | 0/3 | 0/3 | 3/3 | 0/3 | 3 / 0 | 0 / 0.0 | 1965 / 655.0 |
| 纠错 | 旧版本全文 | 0/3 | 3/3 | 0/3 | 0/3 | 3 / 0 | 255 / 85.0 | 2148 / 716.0 |
| 纠错 | 证据纠错后全文 | 3/3 | 0/3 | 0/3 | 0/3 | 4 / 1 | 312 / 104.0 | 3086 / 1028.7 |
| 遗忘 | 无记忆 | 0/3 | 0/3 | 3/3 | 0/3 | 3 / 0 | 0 / 0.0 | 1947 / 649.0 |
| 遗忘 | 过期与有效全文 | 3/3 | 0/3 | 0/3 | 0/3 | 3 / 0 | 477 / 159.0 | 2352 / 784.0 |
| 遗忘 | 清理后全文 | 3/3 | 0/3 | 0/3 | 0/3 | 3 / 0 | 237 / 79.0 | 2112 / 704.0 |
| 预算 | 全部正文 | 3/3 | 0/3 | 0/3 | 0/3 | 3 / 0 | 4884 / 1628.0 | 6795 / 2265.0 |
| 预算 | 三条索引 | 3/3 | 0/3 | 0/3 | 0/3 | 6 / 3 | 990 / 330.0 | 6195 / 2065.0 |

所有均值都是 3 遍的算术平均。初始记忆只计算注入的记忆正文或索引；累计请求计算每次实际发送的完整提示词，包含协议、问题、记忆和后续 Observation，瞬时重试也会计入。本次三片没有发生重试。

本次观察到三件事：

1. **纠错组出现了答案差异。** 旧版本全文 3/3 被 `NORTH-17` 污染，证据纠错后 3/3 回答 `EAST-42`；无记忆组 3/3 拒答。治理组有一遍先读正文再回答，因此它的累计请求均值反而最高，不能把准确率变化写成成本下降。
2. **遗忘组没有出现准确率差异。** 未治理组和清理组都 3/3 选择当前时间；清理只带来本次上下文和请求字节下降，不能宣称它提高了这组题的正确率。
3. **预算组保持答对，但多了一次读取。** 两组都 3/3 回答 `ZX-731`。索引组每遍初始记忆从 1628 字节降至 330 字节，累计请求从 2265 降至 2065 字节，同时 LLM 调用从每遍 1 次增至 2 次。目标记忆三遍都进入索引，索引读取也都命中目标。

这些结果只覆盖单模型、每臂 3 遍的小样本。真实客户端没有设置可控随机种子，重复结果不声称独立同分布；不做统计显著性判断，也不向其他模型、其他任务或普遍成本收益外推。
